# Paxor Security Policy

Security is an important part of the Paxor ecosystem. We appreciate responsible reports from security researchers, developers and users who discover potential vulnerabilities.

## Reporting a Security Issue

If you believe you have discovered a security vulnerability affecting Paxor, please report it privately.

**Security contact:** mail@paxor.pro

**Security & Trust:** https://paxor.pro/security

Please include, when possible:

- a clear description of the issue;
- the affected Paxor component or feature;
- steps required to reproduce the issue;
- the potential security impact;
- relevant screenshots, logs or technical details that may help us investigate.

Please do not include passwords, seed phrases, private keys or other sensitive credentials in a report.

## Responsible Disclosure

Please do not publicly disclose a potential vulnerability before Paxor has had a reasonable opportunity to investigate it.

We ask security researchers to:

- avoid accessing or modifying data that does not belong to them;
- avoid disrupting Paxor services or infrastructure;
- avoid social engineering, phishing or physical attacks;
- avoid actions that could compromise user accounts, wallets or assets;
- report findings privately and provide sufficient information for investigation.

## Security Features

Paxor includes security mechanisms such as:

- session and device monitoring;
- email confirmation for supported sensitive account actions;
- trusted wallet addresses;
- WebAuthn passkeys for selected sensitive actions;
- Guardian protection and risk evaluation;
- security activity logging.

Security mechanisms may evolve as Paxor continues development.

## Scope

This policy applies to security issues affecting Paxor services and functionality operated as part of the Paxor ecosystem.

Third-party blockchain networks, wallets, browser extensions, smart contracts, APIs and other external services may have their own security policies and disclosure procedures.

## Development Status

Paxor is under active development.

Security controls, supported networks and platform functionality may change as development continues.
