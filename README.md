## About Paxor

Paxor is being developed as a connected Web3 ecosystem where users can interact with blockchain networks, manage wallets, work with digital assets, explore music and NFT functionality, and use AI-powered tools from a unified interface.

The project is under active development. Features and supported services may evolve as the platform grows.

## Ecosystem

Paxor currently includes or is developing functionality around:

- **Web3 Wallet** — wallet connectivity and blockchain asset management.
- **Transactions** — tools for sending assets and interacting with supported blockchain networks.
- **Swap** — token swap functionality for supported networks and assets.
- **Paxor Music** — Web3-oriented music and digital content functionality.
- **NFTs** — NFT-related tools and marketplace functionality.
- **AI / Leya** — AI-powered functionality integrated into the Paxor ecosystem.
- **Analytics** — tools for presenting blockchain and account-related information.
- **Security / Guardian** — account and transaction protection mechanisms.

## Security & Trust

Security is an important part of the Paxor architecture.

The platform includes security functionality such as:

- session and device monitoring;
- email confirmation for supported sensitive account actions;
- trusted wallet addresses;
- WebAuthn passkeys for selected sensitive actions;
- Guardian protection and risk evaluation;
- security activity logging.

More information is available on the official security page:

**https://paxor.pro/security**

Security issues can be reported privately to:

**mail@paxor.pro**

Please do not disclose potential vulnerabilities publicly before they have been reviewed.
